# CloudDeck 0.2.2

CloudDeck is a read-only browser for your cloud resources. It never changes anything in your cloud.

## New

- Providers are plugins. AWS and GCP now ship as bundled plugins inside the app.
- Plugins window lists the plugins that are installed.
- About CloudDeck window shows the version, the commit and the plugin list. A Copy button copies these details.
- The provider picker has an All providers view and a Provider column.
- A generic region and zone picker.
- Group by in the table, and a column chooser.
- Per-plugin settings in Settings.

## Changed

- The AWS SDK is no longer part of the core app.
- AWS settings now live under the Amazon Web Services category in Settings.

## Known limits

- GCP signs in with gcloud application-default credentials only.
- Installing third-party plugins is switched off in this release.
