# CloudDeck 0.2.0

This is the first CloudDeck release. CloudDeck is a desktop app for browsing and managing your AWS resources.

## Installing on macOS

The macOS app (Apple silicon) is ad-hoc signed, not notarized by Apple. The first time you open it, right-click `CloudDeck.app` and choose Open, then confirm. After that it opens normally.

## Updates

CloudDeck checks for new releases and can offer them from a Software Update window. Nothing installs silently. Every download is checked against a signed release manifest before it is used.
